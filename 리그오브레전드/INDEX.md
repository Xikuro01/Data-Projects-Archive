# 읽는 순서 안내 (INDEX)

이 폴더는 결과물만이 아니라, 프로젝트가 진행된 순서 그대로의 과정
파일을 함께 담고 있음. 분석 보고서는 `README.md`에 있고, 이 문서는
각 파일을 어떤 순서·목적으로 보면 되는지 안내하는 용도임.

---

## 0. 먼저 볼 것

**`README.md`** — 최종 분석 보고서. 프로젝트 목적, 가설, 방법론,
결과, 한계, 결론이 정리되어 있음. 아래 과정 파일들은 이 보고서가
어떤 과정을 거쳐 나왔는지 보여주는 근거 자료임.

---

## 1. `01_가상데이터_버전/` — 방법론 사전 검증 단계

실제 API 데이터를 쓰기 전, 그룹 정의(포지션+라인전 여부)와 Z-score
로직 자체가 타당한지 가상의 정답 라벨로 먼저 검증한 단계.

| 순서 | 파일 | 설명 |
|---|---|---|
| 1 | `setup_lol_db.py` | 가상 사망 이벤트 데이터 생성 및 DB 적재 |
| 2 | `lol_troll_detection.sql` | 그룹 정의·Z-score 판정 로직 (분석 로직은 전부 SQL에 작성) |
| 3 | `run_lol_sql.py` | 위 SQL 실행 러너 |
| 4 | `lol_death_location_by_group.py` | 그룹별 기준선 시각화 |
| 5 | `lol_death_location_by_group.png` | 시각화 결과물 |

---

## 2. `02_실데이터_버전/` — 실제 API 데이터 적용 단계

Riot Match-V5 API로 수집한 실제 20경기 데이터에 위 방법론을 적용한
단계. 좌표 기반 적진 판정, 팀 판별, 분석단위 수정 등 실데이터라서
새로 생긴 문제들을 처리함 (자세한 내용은 `README.md` 3.2절 참고).

| 순서 | 파일 | 설명 |
|---|---|---|
| 1 | `lol_death_events_real.csv` | Riot API로 수집한 원본 사망 이벤트 데이터 |
| 2 | `lol_analytics.db` | 원본 데이터 적재 DB |
| 3 | `lol_troll_detection_real.sql` | 좌표 기반 적진 판정 + 그룹/Z-score 로직 (실데이터 버전) |
| 4 | `run_lol_sql_real.py` | 위 SQL 실행 러너 |
| 5 | `lol_death_location_by_group_real.png` | 실데이터 기준선 시각화 결과물 |
| 6 | `lol_hypothesis_test.py` | 그룹 간 차이 통계 검정 (Kruskal-Wallis, Mann-Whitney) |

---

## 3. 요약: 무엇이 왜 바뀌었는가

| 단계 | 목적 | 검증 방식 |
|---|---|---|
| 가상 데이터 버전 | 그룹 정의·Z-score 로직 자체의 타당성 확인 | 가상 정답 라벨 대비 정밀도/재현율 |
| 실데이터 버전 | 실제 데이터에서 가설의 방향성 및 통계적 유의성 확인 | Kruskal-Wallis / Mann-Whitney 검정, 개별 사례 실전적 검증 |

두 단계를 거치며 프로젝트의 목적 자체도 "트롤탐지 정확도 향상"에서
"가설의 통계적 검증 및 오탐 감소 가능성 제시"로 조정되었음. 이 조정의
배경과 최종 결론은 `README.md`에 정리되어 있음.
